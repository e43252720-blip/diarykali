# Diary Frontend

Next.js diary / journal application with TypeScript & TailwindCSS — clean, responsive, component-based.

## 🔧 Features

- Next.js 14+ App Router
- TypeScript type safety
- TailwindCSS styling
- Responsive design

## 🚀 Quick Start

```bash
npm install
npm run dev
```

## 🛠️ Stack

Next.js, TypeScript, TailwindCSS

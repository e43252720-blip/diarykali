# 📔 Diary Frontend

> Next.js diary app dengan TypeScript & TailwindCSS untuk manajemen jurnal personal

## 🔥 Features

- ✅ Next.js 14+ dengan App Router
- ✅ TypeScript untuk type safety
- ✅ TailwindCSS untuk styling modern
- ✅ Responsive design
- ✅ Component-based architecture

## 📦 Installation

```bash
git clone https://github.com/e43252720-blip/diary-frontend.git
cd diary-frontend
npm install
```

## ⚡ Quick Start

```bash
# Development mode
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## 🛠️ Tech Stack

- **Framework:** Next.js
- **Language:** TypeScript
- **Styling:** TailwindCSS
- **Icons:** Lucide React

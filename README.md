# CalmDesk

CalmDesk adalah dashboard minimalis yang berisi Diary, Notes, Mini Game, dan Music Player berbasis Next.js (App Router) + TypeScript + Tailwind CSS.

## Menjalankan proyek
1. Instal dependensi:
   ```bash
   npm install
   ```
2. Jalankan server pengembangan:
   ```bash
   npm run dev
   ```
3. Buka `http://localhost:3000` di browser.

Data Diary, Notes, dan pengaturan Music/High Score disimpan di `localStorage` sehingga tidak membutuhkan backend.
